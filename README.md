# CNN Image Classification

CIFAR-10 image classification using Convolutional Neural Network (CNN) and PyTorch.

## Dataset
- CIFAR-10 dataset
- 10 image classes
- 50,000 training images
- 10,000 test images

## Technologies Used
- Python
- PyTorch
- Torchvision
- CNN

## Model
The CNN consists of:
- Convolutional layers
- ReLU activation
- Max Pooling
- Fully Connected layers

## Training
The model was trained using:
- Cross Entropy Loss
- Adam Optimizer
- 20 epochs

## Result
Test Accuracy: **74.27%**
